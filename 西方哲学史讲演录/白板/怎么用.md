# 白板与图谱怎么用

日常用 **Excalidraw**。三张旧 Canvas 留着对照，不删。自动 **图谱** 另算一套，看谁链过谁。

同名文件各有一份，链的时候带上后缀，避免点错：

| 看什么 | Excalidraw（主图） | Canvas（对照） |
|--------|-------------------|----------------|
| 师承、对打、合题、叫醒 | [[人物关系.excalidraw]] | [[人物关系.canvas]] |
| 本原／理念／物自体这条主线 | [[知识图谱.excalidraw]] | [[知识图谱.canvas]] |
| 12 讲怎么接 | [[全书线索.excalidraw]] | [[全书线索.canvas]] |
| 谁链过谁、一张网有多密 | 核心 **图谱**（`Ctrl+G`） | — |

## 1. 白板（Excalidraw）

打开 `白板/` 里任意一张图：

- **滚轮**缩放，拖空白处平移。
- **拖整张卡片**（色块和字是一组，不会把样式拖丢）。
- **Ctrl + 点**卡片打开笔记；普通点是选中，不是跳转。
- 线的颜色：橙偏师承，红偏对打，绿偏合题，紫偏叫醒／翻转。
- 自己也可以再画箭头、涂一笔，不会打乱 Markdown 正文。

要和旧白板对照：同一窗口再开对应的 `.canvas`。日常改图改 Excalidraw 即可。

## 2. 自动知识图谱

1. 打开任意章节或人物卡。
2. 右侧打开 **本地图谱**（只看这一页的邻居），比全书图谱清楚。
3. 全书图谱：过滤 `path:西方哲学史讲演录`，并按标签上色：
   - `#人物`
   - `#术语`
   - `#章节`
   - `#moc`

本地图谱适合「这一讲连出了谁」；白板适合「作者课堂上怎么串」。

## 3. 不要和这两张搞混

- Mind Map 插件：把**单篇**大纲变成树，不是人物关系网。
- Bases 表：索引，不是图。
