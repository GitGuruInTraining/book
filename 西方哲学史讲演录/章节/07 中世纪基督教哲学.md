# 第七讲 中世纪基督教哲学

> [!abstract] 一句话
> 主线不是「黑暗一千年」，而是理性如何在信仰母腹里长大：教父用信仰压理性，经院请来理性当辩护律师；律师后来会变成公诉人。

上一篇：[[06 希腊哲学的衰颓]] · 下一篇：[[08 近代哲学的转向与英国经验论]]

## 1. 结构

书中两大节：[[教父哲学]]；[[经院哲学]]。约 11 世纪为界。

```mermaid
flowchart LR
    T[德尔图良] --> Aug[奥古斯丁]
    Aug --> Pel[佩拉纠]
    Pel --> Ans[安瑟尔谟]
    Ans --> Aq[托马斯]
    Aq --> RB[罗吉尔·培根]
```

作者近二十年研究基督教却非信徒，卡在信仰背景，不是证据谁更强。读这一讲先把自己放回「罪、死、救赎」的生存问题里，再看希腊理性为什么突然不够用。正文跟书走。重要关节把推论写出来。人物卡写生平与后世纪，不在这里重复履历。

## 2. 教父哲学

希腊底色是理性：本原、存在、理念，都可以拿出来辩。基督教从罗马时期改问超理性的生存：人为什么有罪、死往哪里去、谁能救。最初约 250 年受迫害，希望全在彼岸；希腊辩证法对殉道者「分文不值」，不是因为教父笨，是因为当时理性回答不了刑架上的那一句。

处境一变，态度跟着变。国教化之后，人人从生到死都在教会光环下；一套高级宗教不能只靠口号，必须有可教、可辩、可写进学院的体系。于是理性被请来当辩护律师。作者判断：律师后来会变成公诉人。18 世纪启蒙理性，最初正是经院里给教义找论证的那点理性。

传入希腊罗马必须适应土壤：早期偏柏拉图／新柏拉图（神秘、等级、流出）；十字军之后，亚里士多德逻辑经伊斯兰世界回流，经院才用《工具论》以外的亚氏把神学做成可演算的系统。

三大论域：[[三位一体]]、基督论（卡尔西顿「四道围墙」：完全神性＋完全人性，不混、不变、不分、不离）、人性论（[[原罪]] 与救赎）。作者认为人性论理论上更「核心」，因为它直接关生存，不只关天上有几个位格。

> [!note] 书外补
> 演讲只点「伊斯兰回流」。背景是：希腊文本多在拜占庭和阿拉伯世界保存；12 世纪大量译成拉丁文，巴黎、牛津才真正「遇见」完整的亚里士多德。没有这一步，后面的五路证明和共相之争都长不出来。
>
> 宗教改革的前因也要提前看见：教皇权盛极时，赎罪券把恩典卖成门票。作者认为这是信仰虚假的根。路德、加尔文咬的，正是奥古斯丁那条「恩典是因、善功是果」——中世纪后期把因果卖反了。

### 2.1 [[德尔图良]]

2–3 世纪，基督教还在罗马世界里争合法。对手不是后来经院里的逻辑学究，而是希腊常识理性：一不能是三，死人不能复活，童贞女不能生子。若按雅典法庭的标准，教义件件「荒谬」。

要么把奥秘削成希腊人听得懂的哲学（那就不再是启示），要么承认有限器皿装不下大海，把「荒谬」的判词还给理性自己。他选后者。口号对着 [[三位一体]] 这类奥秘，不是对着「二加二等于五」。

希腊理性的工作方式是：对象必须能被概念抓住，不能抓住的就判为不可能。上帝若是无限，被抓住的那一刻已经被限定了——「规定即否定」，阿派朗那一课在这里变成神学。

理性是受造的、有边的。它量得动桌子，量不动创造桌子的那一位。「荒谬」是有限理性对溢出自身之物的判词，不是对象自己的履历。器皿装不下，该反省的是器皿。若三位一体能被演绎出来，它就不再是启示，而是几何。启示的标记恰恰是：常识推不到，还要你信。因此「正因为荒谬，所以我才相信」不是反智狂欢，是把信仰的对象放在理性管辖权之外。先信，不是因为已经想通，是因为想通的那条路根本不通向这里。

作者不要你先笑成蒙昧。四次大公会议的经验也在帮他：被定为正统的，几乎都是理性抓不住的奥秘；被斥为异端的，反而更好懂——更好懂，往往是因为已经把神削成了人能算的东西。

说法就一句：信仰压理性。极端，但把问题摊开了：基督教若要进希腊罗马，必须先决定理性有没有资格当终审。下一站不是把理性灭掉，而是奥古斯丁的「先信后理解」——信了之后，还是要理解。再下一站，安瑟尔谟把理解做成义务。德尔图良的极端，是后面整条「理性在母腹里发育」的起点：先有压，才有请，才有反噬。见 [[德尔图良]]。

### 2.2 [[奥古斯丁]]

西罗马正在垮。他本人走过摩尼教的善恶二元、新柏拉图的流出说，33 岁受洗。桌上同时有三道题。希腊说「无中不能生有」；柏拉图的工匠神还要材料＋理念。若上帝也要材料，祂就不是绝对的。若上帝全善，恶从哪来？摩尼教的答案是：另有一个恶的本原。那就有两个神。若人能靠己力为善，基督的十字架只是榜样；[[佩拉纠]] 正在把这条路走到底。

他还要回答一个嘲讽：「创世以前上帝在干什么？」——若答「在准备地狱给问这种问题的人」，只是赌气；若认真，必须先问「以前」这个词还成立不成立。

与 [[托马斯·阿奎那]] 并列为中世纪两大柱：他是柏拉图式、「先信后理解」；阿奎那是亚里士多德式审慎。

若上帝需要现成质料，质料就是与上帝并列的第二永恒。柏拉图的德穆革是工匠，不是创造者。要把「唯一」保住，创造只能是 [[无中创世]]：用语词，不从仓库里取材料。先造无形「种质」，再有有形万物——逻辑上有先后，时间上同时。这一步不是诗，是为了堵住「还有一个上帝没造的东西」。

若时间在创世前就在，时间就是上帝没造的容器，「创世前祂在干什么」就成了真问题。所以时间、空间也必须是受造的。「以前」是时间内部的语法；没有时间，就没有「以前」。永恒不是「子子孙孙无穷匮也」那种延长，是超时间的俯瞰。时间本身呢？他不把它做成客观的空管子，而做成流逝事物留在心灵上的印象：过去在记忆里，现在在注意里，未来在期待里。作者极推崇这一步，近康德——时间是心灵的形式，不是物自己的属性。

若恶是一种「东西」，造它的要么是上帝（上帝就不全善），要么是另一个神（摩尼）。两条都死。剩下的路：恶不是实体，是 [[善的缺乏]]，像破洞不是一种布。自由是上帝的礼物；罪是人滥用自由（偷食禁果）。礼物本身是善，误用不是另造了一种恶实体。

佩拉纠说亚当只是坏榜样，人可靠自由意志为善。推一步：若人能自救，[[原罪]] 不是必须的，恩典不是必须的，基督救赎变成可选项。奥古斯丁对打：堕落之后本性已败坏，不是「还能选、只是选得差」；能上来的那一步，只能是白白恩典。谁得救，创世时已定。善功是被拣选的**果**，不是买票的**因**。这就是 [[预定论]]。不是「可以躺平」——被拣选者必显善功；是「你不能把善功拿去跟上帝讨价」。

说法收成四块：无中创世、主观时间、恶为缺乏、预定论。方法口令：先信后理解。一头通向经院：已经信了，才谈得上理解，安瑟尔谟把理解升级成义务。一头通向宗教改革：路德、加尔文咬的是「恩典是因」。中世纪后期赎罪券把上帝变成收门票的守门人——因果卖反了。作者认为这是信仰虚假的根，终激出宗教改革。见 [[奥古斯丁]]。

> [!note] 书外补
> 《忏悔录》里的时间分析、对摩尼的论战、与佩拉纠往复，演讲都只点结论。外读不必先啃《上帝之城》：先读《忏悔录》卷十一（时间）＋任何一页「原罪／恩典」对照，再回这一节。

### 2.3 [[佩拉纠]]

他面对的是奥古斯丁那套「人从根上坏了」。若上帝公义，凭什么因亚当一人的过犯，把罪写进所有婴儿？若自由意志在堕落之后已经废了，道德劝勉、修行、法律都变成演戏——你无法对一台坏掉的机器说「你应当」。

他要保住两样：上帝的公义，和人的责任。

惩罚必须以当事人能负责为前提。遗传的罪责，听起来不像公义。因此亚当的堕落主要是坏榜样，不是改写了人性的源代码。后人生下来仍有选择为善的能力；恩典是帮助，不是唯一引擎。基督仍然重要——但是作为榜样与教导，不是作为唯一能重写本性的那一位。

这一步在伦理上干净，在教义上致命：救赎从「必须」变成「加分项」。后世定为异端。演讲报名不介绍，只要记住这一刀：若人能自救，原罪和恩典都不是必须的。作者用他衬托：为什么人性论比三位一体更「核心」——它直接决定十字架还剩多少工作要做。宗教改革仍在咬「恩典还是善功」，佩拉纠是那条线的另一端。见 [[佩拉纠]]。

## 3. 经院哲学

仍是神学婢女，但不再强调理性与信仰对立。正统口号：[[信仰寻求理解]]（安瑟尔谟、阿奎那）。更激进：理解导致信仰（阿伯拉尔），后被斥异端。共同点：都承认理性对信仰要紧。理性像瓶子里的魔鬼，放出来就控不住。

### 3.1 [[安瑟尔谟]]

11 世纪，信仰已经稳了，学院要的不是再喊「信」，而是：已经信了的人，能不能把信的对象想清楚？只信不求理解，他骂成懒惰；懒惰是罪。

上帝存在若只能靠圣经引文，对外邦、对学院里的逻辑学徒没有用。他要一条不靠感官观察、只靠「上帝」这个观念本身就能走完的路。这就是后来叫 [[本体论证明]] 的那一刀。共相上，他还要对打洛色林：若「人」「神」只是声音，三位一体立刻散成三个神。

从定义起，不从观察起。人人（包括愚人）心里都有一个观念：上帝是「无法设想有比祂更伟大者」。这个观念至少存在于知性中。问题是：祂是否也在现实中。「只在心里」比「心里有、现实也有」少了一截。少了一截，就不是最伟大者。因此，若你承认那个定义，又否认现实存在，你是在同一句话里自打嘴巴。所以：最完满者必含存在；上帝＝最完满者 → 上帝存在。

注意他没有说「我看见了第一推动」。他是在拆一个已经信了的观念：完满若不包含存在，完满这个词就没说完。高尼罗用「最完美的迷失岛」反驳：按你的逻辑，岛也该存在。安瑟尔谟的回手（演讲点到为止）：岛是有限一类里的「最」，上帝不是一类里的冠军，是「不能再大」本身；存在对有限物是可加可减的属性，对「最完满者」却是定义的一部分。作者不认为他赢了：这是用一个信仰命题推另一个。康德以后更硬：存在根本不是属性，口袋里一百块与观念里一百块，金额一样。

意义不在证明成功，在开了用逻辑证教义的风气。理性被请上证人席，就很难再请下去。

共相上同构：一般者若只是名，个别的「父、子、灵」就只是三个叫「上帝」的东西。要保住「真是一体」，[[共相]] 必须比名字硬，必须先于、独立于个别。这是极端 [[唯实论]]。笛卡尔再翻一版（从「我不完满」推出完满上帝）。康德终审。见 [[安瑟尔谟]]、[[本体论证明]]、[[信仰寻求理解]]。

### 3.2 [[托马斯·阿奎那]]

13 世纪，亚里士多德整套进来了。柏拉图式的「从完满观念往下跳」，在新教材面前显得太陡：经验世界里明明有运动、因果、目的，为什么不从人人看得见的地方往上爬？

同时要处理共相：极端唯实论把一般者做成独立实体，像第二套柏拉图；极端唯名论又护不住三位一体和圣餐。他要一条中间路：共相既不能飘在个别之外，也不能只是声音。

从「最完满者」起跳，起点已经是信仰里的上帝。对还没信的人，这是循环。他改从感觉系列上溯——看起来更经验，也更亚里士多德。

五路的同一骨架。推动、因果、偶然—必然、完满等级、目的性：五条都是「这一串不能没有首项」。没有第一推动，后面的球动不了；没有第一因，结果链悬空；没有必然者，全是偶在的世界随时可以不在；没有最完满，完满的等级没有尺子；没有理智，自然的朝向没有解释。首项，就是人们所说的上帝。

作者／罗素在这里加两刀，必须自己走完。「没有首项的数列不可能」是预设，不是观察。经验只看见「这一段有因」，看不见「无限后退不可能」。就算要首项，凭什么＝基督教那位三位一体、道成肉身、末日审判的上帝？中间还差一整本教义。仍靠事先的信仰把首项认领回去。

所以五路比本体论「更经验」，并没有走出信仰。理性仍是婢女，只是这位婢女开始用感官当梯子。

温和实在论三句，是为了同时保住创世与认识。创世前，共相在上帝心中（先于个别）——否则上帝按什么造「人」？创世后，共相寓于个别——否则个别没有本性，只是一堆无规定的材料。认识上，共相又后于个别——人是从这匹马、那匹马里抽象出「马」，不是先看见天上的马。

三位一体、圣餐变体说要的是前两句：本质真有，饼酒才能「真变」成体血，而不只是象征。第三句给经验留门：认识从个别开始。这扇门，方济各那边会推得更大。

正统多明我主流把他做成官方神学。另一面：一旦允许从感性细节往上爬，有人就会往下再追——复活成几岁、亚当有无肚脐。奥秘会被笑死；却也打开经验／细节之门，利于近代科学破壳。方济各「三杰」反他：上帝意志绝对自由，理性证神无效，哲学与神学分家。见 [[托马斯·阿奎那]]。

### 3.3 [[罗吉尔·培根]]

阿奎那把亚里士多德逻辑做成证神的工具。方济各这边更刺耳的问题是：若上帝的意志绝对自由，祂可以按另一种样子造世界——那你从「必须如此」推出来的上帝，推的是逻辑必然，不是这位自由的上帝实际做了什么。

他还看见经院越辩越细、离可观察的事物越远。要认识上帝写下的另一本书（自然），不能只在概念里打转。

> [!warning] 两个培根
> 罗吉尔·培根 ≠ 下一讲的弗朗西斯·培根。

若上帝可以不这样造，则「从概念必然推出世界必须如此」这条路是断的。断了之后，剩下的办法是：去看祂实际怎么造——观察、实验、数学。经验在这里不是反信仰，是读第二本书。第一本是圣经，第二本是自然。因此哲学不该再给神学当必胜的律师；两门学问要分家。证神无效，不是因为上帝假，是因为自由的上帝不受你的必然推理绑架。

司各特、奥卡姆是同路：意志优先、共相弱化、个别凸出。作者从这里接到下一讲英国经验论——经院这头「形而上学怪兽」在母腹里意外怀上了感觉经验的胎儿。奥卡姆剃刀把共相剃薄，个别事物走上前台。下一讲弗朗西斯·培根的归纳、四假象，气质上接的是这一支，不是阿奎那的五路。见 [[罗吉尔·培根]]。

## 4. 逻辑链

```mermaid
flowchart LR
    A[德尔图良：信仰压理性] --> B[奥古斯丁：先信后理解]
    B --> C[亚里士多德回流]
    C --> D[安瑟尔谟：信仰寻求理解]
    D --> E[阿奎那：五路＋温和实在]
    E --> F[证明把理性放出]
    F --> G[细节拆神学 / 经验方向长出]
    H[共相之争] -.-> D
    H -.-> E
```

信仰压理性（教父）→ 奥古斯丁先信后理解 → 亚里士多德回流 → 信仰寻求理解 → 证明把理性放出 → 细节拆神学、经验方向长出 → 共相之争平行插入，神学后果把它拽回婢女地位。近代反过来用这点理性审判信仰。

## 6. 复盘

- [ ] 能讲清德尔图良当时的死结：不是「反智」，是有限理性管不管无限对象
- [ ] 能从「人若能自救」推出佩拉纠为何掏空救赎，而不只背「预定论」四个字
- [ ] 能说明本体论证明与五路为何都还在信仰里打转
- [ ] 能用三位一体或圣餐说明共相之争不是纯哲学游戏

> [!question]- 参考（先自己答）
> 德尔图良：「荒谬」是希腊常识理性的判词；器皿装不下大海，信在理先。安瑟尔谟／阿奎那：已经信了，再用逻辑锦上添花。本体论从「最完满者」推出存在，五路从经验上溯首项——都预设没有无首项的数列，且首项＝基督教上帝，仍在信仰里打转。佩拉纠若成立，原罪和恩典都不是必须的。共相若只是名，三位一体易成三神、圣餐易成象征；唯实论要保住「真是一体」「真变体血」。见 [[07 中世纪基督教哲学#2.1 德尔图良]]、[[07 中世纪基督教哲学#3.1 安瑟尔谟]]。
