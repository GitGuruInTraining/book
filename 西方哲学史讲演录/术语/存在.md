# 存在

> [!info] 一句话
> 巴门尼德总句：存在者存在，非存在者不存在。没被指成某物，就是本质——数、一、[[逻各斯]] 那条线的收口。

## 含义

他没有把「存在」指成水、火或任何一块摸得着的料。顺着克塞诺芬尼的「一」、毕达哥拉斯的数、赫拉克利特的 [[逻各斯]] 往下认，它就是现象背后那个不生不灭、唯一、不动的本质；「非存在」则是生生灭灭的杂多现象。所以「存在者存在，非存在者不存在」听起来像同语反复，其实是在切断赫拉克利特那条复线：只留暗线，把可感的生灭从「真」里开除出去。课上也说成「是者是，不是者不是」，being / to be 与「是」「有」相通，作者沿用「存在」这个译法。

他还加了一句：能被表述、被思想的才是存在。本质眼看不见，若承认有本质，它就只能是思维对象。不能被思想又不能被言说的，在他那里等于什么也不是。空间上他把存在说成滚圆的球，因为毕达哥拉斯认为有定形优于无定形、球形最完满（球心到球面各点等距）；时间上却无始无终。时间无限与空间有限打架，弟子麦里梭后来把空间也改成无限，[[高尔吉亚]] 会拿这点做文章。

用他的词写三派公式：他自己是「存在者存在，非存在者不存在」；米利都是「存在者不存在，非存在者存在」；赫拉克利特和后来原子论是两边都存在。柏拉图会把它打碎成许多 [[理念]]。这里的存在不是「这张桌子在不在」，是「能被思想的本质」。推论见 [[巴门尼德]]。

| 立场 | 公式 |
|------|------|
| 巴门尼德 | 存在者存在，非存在者不存在 |
| 米利都 | 存在者不存在，非存在者存在 |
| 赫拉克利特／原子论 | 存在者存在，非存在者也存在 |

## 词源与后来

希腊 τὸ ἐόν / εἶναι，也有人译「是」。being / to be，课上沿用「存在」。柏拉图把它打碎成许多理念。德谟克利特把原子叫存在、虚空叫非存在，却说「非存在也存在」。亚里士多德第一哲学：作为存在的存在。中世「是／存在」之辨（ens / esse）。近代本体论证明把「存在」当完满的一种。康德：存在不是谓词。海德格尔「语言是存在的家」、存在与存在者的区分，是现代回响，课上只点到。

## 容易混的

- ≠ 日常「有没有」。
- ≠ 亚里士多德第一实体（个别物）。对照 [[易混对照]]「实体、实在、存在」。
