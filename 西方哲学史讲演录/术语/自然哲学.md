# 自然哲学

> [!info] 一句话
> 从质料上追问世界：时间上从哪产生，或空间上由什么构成。接近后来的自然科学。

旧教材常把它叫「古希腊唯物主义」。作者不用这个标签当主线，改用「自然哲学 vs [[形而上学]]」。

路线：[[米利都学派]]、[[爱非斯学派]] → [[四根说]] → [[种子说]] → [[原子]]。高峰是 [[德谟克利特]]。近代实验科学很大程度从这条根上长出来。
