# 辩证法

> [!info] 一句话
> 同一个词，各讲不是一个意思。不要用黑格尔去倒灌赫拉克利特，也不要把芝诺的诡辩直接叫「辩证法课」。

| 讲 | 在这本书里指什么 |
|----|------------------|
| 第二讲 | [[赫拉克利特]]：不是「他说了逻各斯所以是辩证法」。火＝过程，逻各斯＝度，度的内容＝对立面互转。三件齐才算。列宁称古代辩证法创始人 |
| 第三讲 | [[芝诺]]：只认间断、不认连续，亚里士多德称他为辩证法奠基者之一——武器是归谬 |
| 第四讲 | 智者／苏格拉底：对话揭矛盾。智者拆，苏格拉底当方法 |
| 第五讲 | 柏拉图通种论：对立范畴在更高者中统一，作者点到黑格尔 |
| 第十一讲 | 康德发现理性阶段必出矛盾，打开近代辩证法；仍把矛盾当「理性的谬误」，有正反无合 |
| 第十二讲 | [[正反合]]、自否定；马克思留下方法、换地基 |

第二讲里还没有这个词当术语用。完整推理在 [[赫拉克利特]] 和 [[02 希腊自然哲学]]：单有火是乱变，单有逻各斯是形而上学暗线，两边扣上才是朴素辩证法。学生克拉底鲁把「不能两次踏入同一条河」推成「一次也不能」——只认运动。反面是芝诺「飞箭不动」。辩证法要在中间求统一。

第一讲：马克思接着黑格尔的辩证法，把头足倒置再倒回来。

## 容易混的

- 课堂「辩证看看问题」＝课本贬义 [[形而上学]] 的反义词，是近代以后的用法。
- 赫拉克利特是独白；苏格拉底是对话。作者特意分开。
