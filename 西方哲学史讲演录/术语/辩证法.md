# 辩证法

> [!info] 一句话
> 同一个词，各讲不是一个意思。不要用黑格尔去倒灌赫拉克利特，也不要把芝诺的诡辩直接叫「辩证法课」。

## 含义

第二讲里还没有这个词当术语用。完整推理在 [[赫拉克利特]] 和 [[02 希腊自然哲学]]。单看「火 + 分寸」，还推不出后来叫辩证法的东西。分寸可以只是命运、数那种「背后有导演」——那是 [[形而上学]] 暗线。辩证法要再问：这分寸管的是什么？管的是烧与灭、生与死如何交替。互相排斥的东西结合在一起，不同的音调造成最美的和谐，一切由斗争产生；我们身上，生与死、醒与梦、少与老是同一个东西，彼此转成对方。有变、有对、有度，三件齐，列宁才把他算成古代辩证法创始人。

当时这个词是稍后被智者和苏格拉底说出来的，主要指通过对话揭露对方逻辑矛盾。赫拉克利特是独白，讲事物自己怎么动，倒有些像后来黑格尔和马克思主义强调的运动变化、对立统一。学生克拉底鲁把「不能两次踏入同一条河」推成「一次也不能」：踏进去的瞬间河已不是同一条，只认运动、不认相对静止。反面以后是芝诺：飞箭不动，只认间断。辩证法要两边一起要。强调相对性时再推一步，就会滑进诡辩——最美的猴子比起人仍是丑的，评价随关系变；推过了，没有任何尺度可靠。[[逻各斯]] 就是那条不让你滑过去的度。

第一讲末尾还点了一笔：马克思接着黑格尔的辩证法，把头足倒置再倒回来。各讲用法见下表。

| 讲 | 在这本书里指什么 |
|----|------------------|
| 第二讲 | [[赫拉克利特]]：火＝过程，逻各斯＝度，度的内容＝对立面互转。三件齐才算 |
| 第三讲 | [[芝诺]]：只认间断、不认连续，亚里士多德称他为辩证法奠基者之一——武器是归谬 |
| 第四讲 | 智者／苏格拉底：对话揭矛盾。智者拆，苏格拉底当方法 |
| 第五讲 | 柏拉图通种论：对立范畴在更高者中统一，作者点到黑格尔 |
| 第十一讲 | 康德发现理性阶段必出矛盾，打开近代辩证法；仍把矛盾当「理性的谬误」，有正反无合 |
| 第十二讲 | [[正反合]]、自否定；马克思留下方法、换地基 |

## 词源与后来

希腊 διαλέγεσθαι：交谈、辩驳。苏格拉底、柏拉图把它做成对话方法；黑格尔把它做成概念自己的运动；马克思留下方法、换地基。课堂「辩证地看问题」＝课本贬义 [[形而上学]] 的反义词，是近代以后的用法。作者还提过一句：辩证法和神秘主义有复杂的内在联系，他当年的博士论文就做这个题目——点到为止，不当本卡的主线。

## 容易混的

- 课堂「辩证看看问题」是近代以后的用法，不要倒灌进赫拉克利特。
- 赫拉克利特是独白；苏格拉底是对话。作者特意分开。
- 有 [[逻各斯]] ≠ 就是辩证法。有尺度还只是暗线；度管对子，三件齐才算。
