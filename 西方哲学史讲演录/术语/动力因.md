# 动力因

> [!info] 一句话
> 使质料动起来、结合起来或分开来的那个原因。

## 含义

词是 [[亚里士多德]] 后来系统化的，作者提前借用，用来看自然哲学里「谁在推」。质料是「由什么做成」；动力是「什么使它成、使它散」。本讲里这个位置一直在挪：

| 人 | 动力放在哪 |
|----|------------|
| [[泰勒斯]] | 灵魂（稀薄物质，像嘘气） |
| [[阿那克西曼德]] | 冷热干湿（内在于阿派朗） |
| [[阿那克西美尼]] | 冷热聚散（内在于气） |
| [[赫拉克利特]] | [[逻各斯]]（分寸，暗线） |
| [[恩培多克勒]] | 爱与恨（**外在**于四根） |
| [[阿那克萨戈拉]] | [[努斯]]（精神、外在） |
| [[德谟克利特]] | 原子自带，不再外求 |

关键的一刀在恩培多克勒。米利都把冷热看成始基本身固有的性质，动力还在质料里面。爱和恨被放在水火土气**外面**推，物质自己就成了惰性的，必须靠外力才能动。[[机械论]] 从这里长：一层一层往外追推动者，最后往往要请一个精神性的第一推动——牛顿让上帝先推一把，不全是信仰，也是这种教养。德谟克利特不走这条：运动是原子固有的功能，质料因和动力因又合一。

## 词源与后来

希腊 αἰτία 里的「动力」这一格，亚里士多德举的例子是工匠、父亲。中世纪五路证明里「第一推动」直接用。近代科学常只留质料＋动力，把 [[目的因]] 赶出自然。第二讲先守「内在还是外在」这一刀。

## 容易混的

- 动力因 ≠ 目的因。努斯既是动力，又暗含目的；德谟克利特要动力、不要目的。
- 「物质自己运动」和「物质必须被推」，在作者看来都是教养的结果，不是纯观察能裁决的。
