# 动力因

> [!info] 一句话
> 使质料动起来、结合起来或分开来的那个原因。

本讲里的演变：

| 人 | 动力放在哪 |
|----|------------|
| 泰勒斯 | 灵魂（稀薄物质） |
| 阿那克西曼德 | 冷热干湿（内在） |
| 阿那克西美尼 | 冷热聚散（内在） |
| 赫拉克利特 | [[逻各斯]] |
| 恩培多克勒 | 爱与恨（**外在**） |
| 阿那克萨戈拉 | [[努斯]]（精神、外在） |
| 德谟克利特 | 原子自带，不再外求 |

爱恨外置，是 [[机械论]] 的源头之一。
