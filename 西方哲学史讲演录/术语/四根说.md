# 四根说

> [!info] 一句话
> 水火土气四种元素都是本原，按比例构成万物。生成论转向构造论的第一站。

生 = 结合，灭 = 分解。爱使其合，恨使其分。四根是 [[质料因]]，爱恨是外在的 [[动力因]]，由此长出后来的 [[机械论]]。

从「一」变成「四」：更好解释，也打开了「用更多本原解释万物」的门，下一站是 [[种子说]]。
