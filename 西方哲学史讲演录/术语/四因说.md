# 四因说

> [!info] 一句话
> 质料、形式、动力、目的。自然物里后三因并入形式。

## 含义

问个别事物：由什么做成、被规定成什么样子、谁使它成、为何要它。房子：砖瓦／蓝图／工匠／居住。自然物：橡树种子是质料，长成的橡树同时是形式、动力、目的——后三因并入形式。阶梯需要端点：纯质料、纯形式（第一推动者）。单有「材料＋形状」是工艺说明；加上内在目的当动力，才连上有机论。口头综合柏拉图与原子论，心偏向形式「更是实体」。见 [[亚里士多德]]。

苏格拉底狱中补上目的因，第四讲预告，第五讲收口。作者提前借用，古人自己没这张表：

| 前几讲说法 | 主要落在哪一因 |
|------------|----------------|
| 水、气、火、四根、种子、原子 | [[质料因]] |
| 爱恨、[[努斯]]、原子自运动 | [[动力因]] |
| 数、[[存在]]、[[逻各斯]]、[[理念]] | 形式 |
| 眼睑牙齿合用、善本身 | [[目的因]] |

## 词源与后来

希腊 αἰτία：原因、责任。外读：《物理学》第二卷选段。中世经院全盘接收，五路证明里推动、目的两路直接用。近代科学常只留质料＋动力（机械论），目的因被赶出自然——作者后文会对照。生物学、行动理论里目的因以「功能」「意图」名义回来，不是同一套四因表。

## 容易混的

- 四因是「何以如此」，不是时间上四个阶段。
- 形式因 ≠ 柏拉图外在理念；亚里士多德要形式寓于个别，又让纯形式在顶端。
