# 怀疑论

> [!info] 一句话
> 作者用来对打 [[独断论]] 的那一极。不是「生活里什么都不信」。

| 讲 | 形态 |
|----|------|
| 第四讲 | [[智者]]：方法上的怀疑，为辩而辩；生活仍要吃饭 |
| 第六讲 | [[皮浪]]：[[悬置判断]] 以求安宁；断定「知识无效」也是判断 |
| 第八讲 | [[休谟]]：经验论推到底，理论里实体不可知；习惯是人生指南 |
| 第十一讲 | 作者评康德：更精致的怀疑论（物自体不可知）叠加更精致的独断 |
