# 还原论

> [!info] 一句话
> 把复杂事物追回到更简单的开端或更小的单元。自然哲学两条问法都是还原。

- **时间还原**：人 ← 猴子 ← 更低等生物 ← 无机物（生成论）
- **空间还原**：人 → 细胞 → 更小微粒 → [[原子]]（构造论）

还原必须有终点，否则没有意义。希腊自然哲学给的终点就是不可再分的原子。[[形而上学]] 不走这条路，它抽象本质，不拆零件。
