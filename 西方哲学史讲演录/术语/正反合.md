# 正反合

> [!info] 一句话
> 费希特补上合题；黑格尔做成肯定—否定—否定之否定。康德只有正反，没有合。

## 含义

德国古典里，矛盾怎么被处理，比「有没有矛盾」更要紧。康德已经看见理性阶段必出对立：四个 [[二律背反]] 正反两边都能自圆。他的办法是限制范畴的运用，把矛盾当成理性的谬误取消掉。对立被打开了，却没有第三者来收。

费希特第一步补上合题。自我设定自身（正），设定非我（反），再设定自身和非我（合）。合题等于自觉：对立双方都在自我里被认出来。谢林接着给这个形式填内容：同一 → 差别／对立／矛盾 → 更高的同一。走出第一步靠的是无意识欲望，黑格尔后来说这是诗，不是逻辑。

黑格尔把三步收成概念自己的运动：肯定—否定—否定之否定。动力不在外面再设一个反题，而在每个规定自己含着对立面。前环节被 [[扬弃]]，不是被抹掉。

> [!definition] 正反合
> 一个规定（正）自己长出对立面（反），再在更高规定里被理解和保存（合）。康德有正反无合；费希特有合题；黑格尔让合题从内在矛盾里长出来。

| 谁 | 正反合到哪一步 |
|----|----------------|
| [[康德]] | 二律背反正反都能自圆，停在对立 |
| [[费希特]] | 自我设定自身 → 设定非我 → 设定自身和非我。合题＝自觉 |
| [[谢林]] | 同一 → 差别／对立／矛盾 → 更高同一。给形式填了内容 |
| [[黑格尔]] | 肯定—否定—否定之否定。动力在概念自己含着对立面 |

作者从第二讲就开始用「合题」当讲述框架：气是水和阿派朗的合题。那是他的讲法，不是米利都自己的口号。第十二讲才算总账。矛盾史可以记成：打开（康德）→ 有合题（费希特）→ 有内容（谢林）→ 自否定（黑格尔）。细表见 [[辩证法]]。

## 词源与后来

教科书常写成 thesis–antithesis–synthesis，黑格尔本人更常说否定之否定。别把一切历史都强行填进三格——作者也嘲他细节上霸道。马克思留下方法。后来「正反合」进了中学政治课，和费希特知识学不是同一套技术。

## 容易混的

- 第二讲的「合题」是讲述语言，不是古人术语。
- 有正反无合 ≠ 已经有辩证法全书。康德打开门，没收圆。
