# 正反合

> [!info] 一句话
> 费希特补上合题；黑格尔做成肯定—否定—否定之否定。康德只有正反，没有合。

## 含义

| 谁 | 正反合到哪一步 |
|----|----------------|
| [[康德]] | 二律背反正反都能自圆，停在对立 |
| [[费希特]] | 自我设定自身 → 设定非我 → 设定自身和非我。合题＝自觉 |
| [[谢林]] | 同一 → 差别／对立／矛盾 → 更高同一。给形式填了内容；走出靠欲望 |
| [[黑格尔]] | 肯定—否定—否定之否定。动力在概念自己含着对立面，[[扬弃]] 前环节 |

作者：康德停在费希特的反题（非我仍是硬设）。第二讲已用「气是水和阿派朗的合题」当**讲述框架**，那是作者的讲法，不是米利都自己的口号。第十二讲才算总账。讲课骨架从第二讲就开始用。矛盾史：打开（康德）→ 有合题（费希特）→ 有内容（谢林）→ 自否定（黑格尔）。见 [[辩证法]] 细表。

## 词源与后来

教科书常写成 thesis–antithesis–synthesis，黑格尔本人更常说否定之否定。别把一切历史都强行填进三格——作者也嘲他细节上霸道。马克思留下方法。后来「正反合」进了中学政治课，和费希特知识学不是同一套技术。

## 容易混的

- 第二讲的「合题」是讲述语言，不是古人术语。
- 有正反无合 ≠ 已经有辩证法全书。康德打开门，没收圆。
