# 历史与逻辑相统一

> [!info] 一句话
> 哲学家出场的时间顺序，和概念自己展开的逻辑环节，是对得上的。

[[黑格尔]]《哲学史讲演录》里明确提出。哲学史不是尸骸战场，是概念自己在长。

第二讲就是第一次演习：抽掉人名，剩下的是质料意义上 [[本原]] 的深化——水 → [[阿派朗]] → 气 → 火 → 四根 → 种子 → [[原子]]。
