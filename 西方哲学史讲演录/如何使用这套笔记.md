# 如何使用这套笔记

这不是一篇长文，而是一个小知识库。打开 [[西方哲学史讲演录]] 当首页。

## 1. 四种笔记

| 类型 | 文件夹 | 干什么 |
|------|--------|--------|
| MOC | 根目录 | 地图、进度、嵌入索引 |
| 章节 | `章节/` | 这一讲的结构、论证、自测 |
| 术语 | `术语/` | 一个词一张卡，供各讲复用 |
| 人物 | `人物/` | 一个人一张卡，学派、命题、下游 |
| 白板 | `白板/` | Excalidraw 主图；三张旧 Canvas 留着对照 |
| 预备 | 根目录 | [[预备概念与外读]]：演讲默认你会的词 + 最短外读 |

## 2. 章节跟书走，卡片写人写词

章节是讲稿的加厚版，**大纲跟书走**（书里的大节名：毕达哥拉斯学派、智者派、柏拉图哲学……）。正文以书中内容为准，补厚两样：作者一带而过的关节，以及比较重要的**推论过程**（他桌上已有什么答案、这一步为什么必须这样走）。不要另开「故事」「当时面对什么／怎么想到」当标题。

书里没有、但读下去需要的背景（生卒、著作、城邦、后来怎么用），用 `> [!note] 书外补`，或写进人物／术语卡。

**人物卡、术语卡**比讲稿全：生平、著作、词源、后世纪用法。推论过程只放章节，卡片用一句话链回去。

| 放哪 | 写什么 |
|------|--------|
| 章节 | 书中内容 + 重要推论；标题用书的大节／人名／学说 |
| 人物 | 生平与著作、主要说法、后世纪、上下游 |
| 术语 | 含义、词源与后来、容易混的 |

## 3. 阅读顺序

1. 先读章节笔记，顺着论证走。
2. 遇到 `[[黄字双链]]` 悬停预览；卡住再点进去。
3. 学完一讲，把章节末尾的复盘任务勾掉。
4. 想串线：白板看「作者怎么讲」，本地图谱看「这一页链出了谁」。详见 [[怎么用]]。
5. 名字或术语拧了，先打开 [[易混对照]]。学完要自测，走 [[复盘]]。
6. 听不懂他「点一下就过」的词，打开 [[预备概念与外读]]；康德章先读第 5 节。

## 4. 语法约定

| 写法             | 作用             |
| -------------- | -------------- |
| `## 1. 标题` / `### 1.1 小节` | 章节标题手写编号，不要用 Number Headings |
| `[[笔记名]]`      | 双链，改名会跟着走      |
| `![[术语.base]]` | 嵌入自动表格         |
| `> [!tip]`     | 高亮块：结论、提醒、自测   |
| `^block-id`    | 精确链到某一句        |
| `- [ ]`        | 复盘任务，可在任务视图里汇总 |

## 5. 属性

每张笔记顶部的 YAML 用来给 Bases 过滤，常见字段：

- `type`：`moc` / `章节` / `术语` / `人物`
- `lecture`：第几讲（`0` 是自序）
- `school`：学派（人物用）
- `status`：`已读` / `进行中` / `待读`
- `aliases`：英文名、别称，方便搜索

## 6. 续写新讲

用模板 `章节笔记`、`术语卡片`、`人物卡片`，再把新术语链回旧卡。不要把所有解释又堆回章节长文里。演讲一带而过的词，写进该章「这本书默认你会」，并链到 [[预备概念与外读]]。

## 7. 插件：不用再装一堆

现成的就够用，**不必为这套笔记再装 Templater、Dataview**。Bases 已经覆盖索引表。

| 要用的 | 类型 | 干什么 |
|--------|------|--------|
| 图谱 / 反向链接 / 页面预览 | 核心 | 点双链、看谁链过谁 |
| Bases | 核心 | 章节、术语、人物自动表 |
| Properties（属性） | 核心 | 看 YAML；已打开 |
| Templates | 核心 | 模板目录指向 `西方哲学史讲演录/_模板` |
| Excalidraw | 已装 | 白板主图：`白板/` 里三张 `.excalidraw.md` |
| Canvas | 核心 | 旧白板对照用，三张 `.canvas` 还在 |
| Homepage | 已装 | 启动打开本套首页 |
| Outliner / Mind Map | 已装 | 大纲和脑图，可选 |

**不要为写笔记新装的：** Dataview（和 Bases 重复）、Templater（核心 Templates 够用）、Number Headings（标题已手写编号，再装会叠号）、各种「哲学插件」。库里已有的 Calendar、Git、Outliner、Mind Map 保持原样即可。

图谱建议：打开任意章节 → 本地图谱 → 过滤标签 `#术语` 或 `#人物`。首页笔记打开的是全书图谱，会比较挤。
