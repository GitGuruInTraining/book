# 预备概念与外读

这本是通识**演讲录**。赵林默认听众已经听过一些词，课堂上点一下就往下走。卡住时先看本页对应节，再点卡片；仍糊，再按「外读入口」补一篇短的，不必先啃全集。

> [!warning] 范围
> 这里补的是「不补就听不懂他在说什么」，不是另写一部哲学史，也不补他明确不讲的现代各派。

用法：[[如何使用这套笔记]]（第 2 节：章节讲故事，卡片写人写词）。拧了的词：[[易混对照]]。自测：[[复盘]]。

## 1. 全书默认的逻辑工具

演讲里「必然」「或然」「归纳推不出」常常一笔带过。

| 词 | 先记成 | 卡片 |
|----|--------|------|
| 归纳 / 演绎 | 从例子往上收 vs 从前提往下推 | [[归纳与演绎]] |
| 分析 / 综合 | 谓语已含在主语里 vs 给主语加新内容 | [[分析与综合]] |
| 必然 / 或然 | 「不可能别样」vs「到目前都这样」 | 经验论死在这一刀，见第八讲 |
| 符合论 | 命题真＝符合外物 | [[符合论]]；休谟、康德都在改它 |

读第八、九、十一讲前，这四行要能用自己的话再说一遍。

## 2. 希腊：他当背景的词

| 词 | 演讲里常怎么用 | 其实还要知道 |
|----|----------------|--------------|
| [[本原]] | 「从哪来 / 由什么构成」 | 亚里士多德后来才系统分成四因；前几讲是作者**提前借用** |
| [[质料因]] / 形式 | 水火原子 vs 数、存在、理念 | [[四因说]] 要到第五讲才收口 |
| [[存在]] | 巴门尼德那条真理之路 | 不是「这张桌子在不在」，是「能被思想的本质」 |
| [[范畴]] | 第五讲点一下十范畴 | 亚氏：存在的分类；康德：认识的形式。不是同一套 |
| [[理念]] | 第五讲核心 | 希腊文 eidos／idea＝看见的形相，**不是**心里的念头 |
| 洞喻 / 线喻 | 第五讲各一段 | 课堂当人人读过《理想国》第七卷 |

**外读（希腊）：** 《理想国》第六–七卷（线喻、洞喻）比先啃《形而上学》省事。四因看亚里士多德《物理学》第二卷选段，或任何一本哲学史的「四因」专节。

## 3. 中世纪：神学他默认你会

第七讲三大论域（三位一体、基督论、人性论）几乎不解释教义本身，只讲哲学后果。

| 词 | 先记成 | 卡片 |
|----|--------|------|
| [[三位一体]] | 独一上帝，父、子、灵三个位格 | 共相之争为什么咬这里 |
| [[原罪]] / [[佩拉纠]] | 人是否从根上坏了 | 掏空救赎 vs 奥古斯丁恩典 |
| [[无中创世]] | 不用现成材料和理念 | 对打柏拉图工匠神 |
| [[善的缺乏]] | 恶不是一种「东西」 | 弃摩尼二元 |
| 圣餐变体 | 饼酒是否真变成体血 | [[唯实论]] 要保住「真变」 |
| 卡尔西顿 | 基督完全是神又完全是人 | 「四道围墙」：不混、不变、不分、不离 |

亚里士多德怎么进拉丁世界：他只说「经伊斯兰回流」。背景是：希腊文本在拜占庭／阿拉伯世界保存，12 世纪译成拉丁文，经院才用《工具论》以外的亚氏。

**外读（中世纪）：** 先读任何简明「基督教基本教义」页（三位一体、原罪、创世），再读第七讲。证明部分看安瑟尔谟《论证》选段 + 高尼罗反驳即可，不必先读《神学大全》。

## 4. 近代：政治和科学他当常识

| 词 | 先记成 | 卡片 |
|----|--------|------|
| [[社会契约]] / [[君权民授]] | 政治权力来自同意，不是神授 | 霍布斯让渡全部；洛克只让渡部分 |
| 光荣革命 | 1688 英妥协立宪 | 洛克是事后理论辩护 |
| [[第一性质与第二性质]] | 广延运动属物；色声香味多属感觉 | 贝克莱从「分不开」砍物质 |
| [[广延]] | 占空间、可量 | 笛卡尔物质的本质；单子因此不能有广延 |
| 身心问题 | 心、物怎么既独立又协调 | [[古典二元论]] → [[身心交感说]] / [[偶因论]] / [[身心平行论]] / [[前定和谐]] |
| 南特敕令 | 法国一度容忍新教，后被废 | 第十讲「双专制」的引线 |
| 里斯本大地震 | 1755 | 伏尔泰嘲「最好世界」；卢梭要给受难者希望 |

**外读（近代）：** 笛卡尔《第一哲学沉思集》前三个沉思；休谟《人类理解研究》（比《人性论》短）；洛克《政府论》下篇看社会契约即可。培根《新工具》看 [[四假象]] 那一节就够。

## 5. 康德课前：这一讲默认最多

第十一讲是全书最陡的坡。下面几个词他常常当已经会。

| 词 | 先记成 | 卡片 |
|----|--------|------|
| [[先天与先验]] | 先天＝不来自经验；先验＝使经验知识可能；超验＝越出经验用 | 三个词绝不能混 |
| [[分析与综合]] | 见第 1 节 | 再和先天／后天拼成四格 |
| [[先天综合判断]] | 既必然又加新内容 | 总问题：如何可能 |
| [[范畴]] | 知性拿来构造对象的格子 | 不是亚氏那十个存在格子 |
| [[先验自我]] | 认识的形式主体，不是心理里的「我」 | 取消它，立法者没了 |
| [[物自体]] | 必须假定、不可认识的来源 | 不是「客观物质」的别名 |
| [[自律与他律]] | 自己立法 vs 怕罚、求福才守规矩 | [[绝对命令]] 只要自律 |
| [[悬设]] | 实践上必须假定，不是证明出来 | 自由、灵魂不死、上帝 |

三大批判他只点「知、意、情」：第一批判知识，第二批判道德，第三批判审美／目的——本讲几乎只讲前两本。

**外读（康德）：** 先读他的《任何一种能够作为科学出现的未来形而上学导论》，再碰《纯粹理性批判》。邓晓芒、赵林合著的专业本《西方哲学史》康德章可当对照，不是替代。

## 6. 德国古典：他当听众听过黑格尔课

| 词 | 先记成 | 卡片 |
|----|--------|------|
| [[扬弃]] | 丢掉、留下、提高，三层一起 | 不是单纯「取消」 |
| [[正反合]] | 费希特补合题；黑格尔做成过程 | 第二讲已当讲课框架 |
| [[绝对精神]] | 实体又是主体，在历史里认识自己 | 逻辑 → 自然 → 精神 |
| 头足倒置 | 马克思：黑格尔把现实倒立成观念 | 辩证法留下，地基换成物质／社会 |
| [[密涅瓦的猫头鹰]] | 黄昏才起飞 | 哲学是事后理解，不是号角 |

**外读（德国古典）：** 黑格尔不必从《逻辑学》开读。先读《精神现象学》序言，或任何一本可靠导论里「存在—无—变易」「主奴」两节。马克思看《关于费尔巴哈的提纲》第 11 条就够接上作者的收课。

## 7. 按讲：最该补的一篇

读某讲觉得「他怎么假定我会」时，按这一列补，不要同时开五本书。

| 讲 | 先补什么 | 最短外读 |
|----|----------|----------|
| 第一讲 | [[形而上学]] 两套意思；唯心／唯物是近代才流行的标签 | 本库卡片即可 |
| 第二讲 | 质料／动力／目的是后贴的标签 | 四因专节 |
| 第三讲 | 「存在」不是日常「有」 | 巴门尼德残篇选译（极短） |
| 第四讲 | [[美德即知识]]；智者不是骂人 | 柏拉图《美诺》前半 |
| 第五讲 | 洞喻、线喻、十范畴、第一推动者 | 《理想国》6–7 卷 |
| 第六讲 | [[三位一体]] 才能懂「太一同构」 | 本库 [[三位一体]] |
| 第七讲 | 教义 + 圣餐变体 | 见上面第 3 节 |
| 第八讲 | [[归纳与演绎]]、[[社会契约]]、第一／第二性质 | 《人类理解研究》 |
| 第九讲 | [[广延]]、身心问题、本体论证明 | 《沉思集》1–3 |
| 第十讲 | [[自然神论]] vs 无神论；[[公意]] vs 众意 | 《社会契约论》第一、二卷选 |
| 第十一讲 | 本页第 5 节整节 | 《未来形而上学导论》 |
| 第十二讲 | [[扬弃]]、正反合、头足倒置 | 《精神现象学》序言 |

对照用的通史：罗素《西方哲学史》故事性强、判断和赵林常相反，适合当「第二意见」，不要当标准答案。作者自己的专业本（与邓晓芒合著）比演讲录密一档，卡住的论证可去对。

## 8. 先不要外读的

- 海德格尔、分析哲学、后现代主义——自序说了不讲，补了会冲掉他的线索。
- 用「物理原子被劈开」去反驳德谟克利特。他要的是思想里的不可分单元，见 [[原子]]。
- 把课堂口味（希腊化是救护车、黑格尔后没落）当成哲学史定理。见 [[易混对照]]「作者口味」。
