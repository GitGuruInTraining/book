# 易混对照

读这套笔记最容易拧在一起的几组。先看表，再点进卡片。

## 1. 重名的人

| 容易当成一个 | 其实是 |
|--------------|--------|
| [[芝诺]] | 爱利亚的芝诺（保一与静）≠ 斯多葛创始人季蒂昂的芝诺 |
| [[培根]] vs [[罗吉尔·培根]] | 近代弗朗西斯 ≠ 13 世纪方济各的罗吉尔 |
| [[克塞诺芬尼]] | 巴门尼德老师 ≠ 史家／苏格拉底学生色诺芬 |
| 麦加拉的欧几里得 | ≠ 几何《原本》的欧几里得 |

## 2. 上帝住在哪

| 说法 | 上帝在哪 | 代表 |
|------|----------|------|
| [[自然神论]] | 悬在自然之上，立法后不管 | [[伏尔泰]]、牛顿式 |
| [[神即自然]] | 化进自然之中 | [[斯宾诺莎]] |
| 无神论 | 从自然里外一起清掉 | [[狄德罗]]、[[霍尔巴赫]] |
| 内心宗教 | 搬进良心 | [[卢梭]] → [[康德]] 道德 |

## 3. 认识上的「观念」

| 词 | 这本书里指 |
|----|------------|
| [[理念]] | 柏拉图：客观本质，不是心里的念头 |
| [[天赋观念]] | 笛卡尔：与生俱来的公理 |
| [[白板说]] | 洛克：心里原先没有那些观念 |
| [[存在就是被感知]] | 贝克莱：物＝可感性质的观念集合 |
| [[印象与观念]] | 休谟：印象鲜活，观念是较弱摹本 |

## 4. 实体、实在、存在

| 词 | 别理解成 |
|----|----------|
| [[实体]]（亚里士多德） | 第一实体是个别物；不是「物质」的同义词 |
| [[唯实论]] | 共相实在，不是「承认桌子在我之外」 |
| [[存在]]（巴门尼德） | 本质／能被思想者，不是「有没有这张桌子」 |
| [[物自体]] | 不可知的质料来源，不是「客观物质」的别名 |

## 7. 辩证法怎么变

同一中文词，各讲不是一个意思。细表见 [[辩证法]]。

| 讲 | 先记成 |
|----|--------|
| 2 | 赫拉克利特：变、对立、尺度 |
| 3 | 芝诺归谬，保一与静 |
| 4 | 对话揭矛盾（拆或接生） |
| 5 | 通种论：对立在更高者里统一 |
| 11 | 有正反，没有合 |
| 12 | 正反合、自否定 |

## 8. 实体怎么变

细述见 [[实体]]。

| 谁 | 实体指 |
|----|--------|
| 亚里士多德 | 第一实体＝个别物；第二实体＝种属 |
| 笛卡尔 | 心、物相对实体；上帝绝对 |
| 斯宾诺莎 | 唯一实体＝神＝自然 |
| 洛克 | 性质下面还要一个基质，经验给不出 |
| 休谟 | 物质、自我、上帝一律存疑 |

## 9. 理性怎么变

| 阶段 | 理性在干什么 |
|------|----------------|
| 希腊 | 尺度、逻各斯、能思想者 |
| 教父 | 装不下奥秘，该低头 |
| 经院 | 给信仰当律师 |
| 启蒙 | [[理性法庭]]，自己不受审 |
| 康德 | 先审能力、范围、界限 |

## 10. 作者口味，不必当定理

讲述立场，不是哲学史公理。读第六、十、十二讲时对照。

| 他常说 | 先当成 |
|--------|--------|
| 希腊化是火炬变救护车 | 城邦崩溃后的伦理转向；伊壁鸠鲁、斯多葛另有一套严肃问题 |
| 放弃本质、只跟感觉走是低谷 | 他的古典主义；20 世纪许多哲学故意走反本质 |
| 法国启蒙机智有余、深刻不足 | 修订版仍坚持必须补上，因为康德要审这股理性 |
| 哲学到黑格尔之后开始没落 | 自序的个人口味；书因此不写现代 |
| 黑格尔历史哲学有西方中心 | 他自己也不讳，不必替他圆 |
