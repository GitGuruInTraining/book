# 正确论证

第 3 章把「对」拆成两件，人常把它们当一个词用。内容真：前提贴着世界。结构通：叫有效，前提真的时候结论不得不跟着来。两件同时在，论证才正确。听权威有时合理；正确论证更高，你自己看见它为什么对。译本把 sound argument 译成「正确论证」，一个词糊住 true / valid / sound，读译本时见 [[读译本时注意]]。

结构对、前提假：每只狗三个头，牧羊犬是狗，所以牧羊犬三个头。车子做得再好，油箱里是水。前提真、跟结论无关：皮埃尔是球星、富翁、笑容好看，所以该选他当州长。句句可以真，没有一句说他会治理。前提真、结构坏：松鼠和熊猫都是哺乳动物，所以熊猫是松鼠。见 [[中项不周延]]。

联言、选言、[[条件论证]]、[[三段论]] 都是在练结构。日常许多「如果天气好就去露营」没有必然联系，结论只是可能——那不是失败，是你不该把它说成必然。
