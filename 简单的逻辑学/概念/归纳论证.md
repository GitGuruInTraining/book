# 归纳论证

第 3 章不要那句教科书口诀——演绎从一般到个别，归纳从个别到一般。更干净的切法：演绎收必然，归纳收可能。两者都有前提和结论。演绎从一个已真的全称出发，把里面已经含着的东西析出来。每棵树有根系，门边白杨是树，所以门边白杨有根系。

归纳从一串特称证据往上收。亨利发现：先伸手去拍，狗跑；先让狗嗅手，狗肯被摸。他对自己那几只狗做完，得到实验性结论。他不可能试遍世上每只狗，所以用样本代表整体。样本要大到能罩住整体里那些不一样的情况。科学多半走这条路；走稳了，归纳会给下一步演绎提供大前提。

从特称硬跳到全称，是第 3 章早就禁过的。克莱尔村你遇见的人都是红发，最多说「也许全村如此」。库里哲学史把同一条缝写成 [[归纳与演绎]]：归纳给新内容，保不住必然；演绎保必然，扩不出去。麦克伦尼站在用的这一边，切法兼容，不另起一套。
