# 追求优越性

青年以为，人一旦追求优越，就得和别人比，退出竞争就等于认输。哲人把追求优越性讲成另一件事。人想摆脱无力，朝理想的自己前进。人学走路、学说话，就是这种欲求。志向大的人，会对那个还没到达的自己感到不够。这种感觉用对了，就会催他去努力。大家站在同一个平面上，这个平面不设上下。人与人的快慢可以不同。每个人要的是自己往前，不是要高别人一等。

哲人接着说，竞争会妨碍人做自己。对手偶尔能帮这个人看清自己，多数时候成不了伙伴。这个人承认错误、退出 [[权力斗争]]，并没有把追求优越性丢掉。他退出的是和别人分高下。他朝理想的自己走的那一股劲还在。

读者容易把追求优越性听成 [[优越情结]]。追求优越性是人往前走。[[优越情结]] 是这个人不肯努力，却用权势、旧功劳或不幸假装自己已经更高。两种听成一种，人就会羞于往前，或者把压过别人当成成长。本书写到第五夜，把「廉价的优越性追求」算进后一种：这个人惹麻烦，好把自己变成特别的人。那一笔记在 [[优越情结]]。

以后读《自卑与超越》，如果原著用别的说法讲同一件事，补在这段下面。
